# C07 — exact source-range property changes

This companion to primitives.rs is the C-owned API for the first six tools.
It is **not** a TeX parser, geometry solver, app document state, or editor UI.

1. Use Catalog::bundled to populate palette, inspector, code hints, and Russian help from the same schema.
2. Use Catalog::generate to create the selected native TikZ command. Its package/library requirements are explicit; the app must present any preamble edit and its undo.
3. The app stores the exact generated command, literal input values, its current source byte range (excluding any app-specific marker/comment), and an authoritative source revision. It must not infer that an unrelated user macro is an owned primitive.
4. To edit a parameter, call primitive_edit::plan_parameter_edit with those values and the **current** document. The command must match its generated bytes exactly; user-modified, opaque, missing, or duplicate/ambiguous commands must remain source-only.
5. Apply the returned SourcePatch using SourcePatch::apply. This verifies the revision and old bytes and returns the inverse patch for undo. A no-op is rejected; the app handles source saving and revision persistence.
6. Native TeX expression source can still be written manually. Only the six editor-generated literal controls accept the restricted dimensions/enums from catalog-v1.toml. Math node content is intentionally user TeX, not sandboxed.

The patch computes the shortest contiguous change by UTF-8 characters. It never rewrites the whole TeX file or silently drops a user macro. A new GUI gesture, installed package, and successful XeLaTeX build are different acceptance dimensions.

Contract example (Rust):

~~~rust
let catalog = Catalog::bundled()?;
let values = BTreeMap::new();
let old = catalog.generate("tikz.circle", &values)?;
let patch = plan_parameter_edit(
    &catalog, "tikz.circle", &values, "radius", "2cm",
    &document, SourceTarget::new(known_command_byte_range, document_revision),
)?;
let undo = patch.apply(&mut document, &mut document_revision)?;
~~~

The application must first verify that the known byte range belongs to this command; code in this crate never searches or rewrites unknown document regions. Physical Windows 10 MiKTeX and M1/M4 GUI tests remain separate.

`SourceTarget` binds range and revision, matching the N1 integration contract; SourcePatch still checks expected source bytes. Unknown TeX stays untouched.
