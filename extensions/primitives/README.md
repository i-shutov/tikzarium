# TikZ-native primitives (catalogue v1)
The bundled TOML file is the **single** schema for six source-first commands: `tikz.line`, `tikz.arrow`, `tikz.rectangle`, `tikz.circle`, `tikz.node`, `tikz.bezier-cubic`. A parameter stable ID is `<tool.id>.<parameter.id>`. Its type, units, choices, preset provenance, Russian help, interaction, warning and primary PGF section are here. All parameter requirements inherit `tools.requirements`.

**Compiler:** external XeLaTeX, no TeX/PGF reimplementation. On Windows 10, install MiKTeX independently; on macOS ARM64, use the user-installed XeLaTeX. Installation metadata is not `\\usepackage{tikz}` or `\\usetikzlibrary{arrows.meta}` in the current project. Code output always belongs beside the corresponding controls; the source remains authoritative.

**Contract for B:** `Catalog::bundled().tools` can feed toolbar, inspector, completions, and help. `generate(id, BTreeMap<String,String>)` returns a native TikZ snippet plus separate requirements, NOT a complete-document rewrite. `SourcePatch` changes exactly one caller-verified byte span at one source revision and yields its inverse for undo. B must own span detection, revision tracking, UI and TeX environment integration; C does not claim interactive editing.

**Contract for D:** `cargo run -p tikzarium-extensions --bin primitive-fixtures > generated.tex` emits the same file as `fixtures/all-six.tex`; the in-crate snapshot test detects drift. Run with `xelatex -no-shell-escape -halt-on-error -interaction=nonstopmode -output-directory <scratch> generated.tex` and inspect one-page PDF. `fixtures/negative-cases.toml` contains literals which must be rejected *before* compiling. Rust tests also check help completeness, text-vs-math handling, stale ranges and undo.

The math node intentionally inserts user-written raw math TeX, not an execution sandbox. Unknown source macros survive untouched. Generic user-installed XeLaTeX-compatible packages remain available for compilation without a visual adapter. Lua-only graphdrawing remains incompatible with XeLaTeX. Manual target: [PGF/TikZ 3.1.12](https://tikz.dev/) sections 14.2/14.3/14.4/14.6, 16.2/16.5, 17.2/17.4; minimum PGF version is UNKNOWN because not independently verified.

**Readable visual QA:** `Catalog::gallery_document()` assembles six isolated labelled scopes from the same generator and is snapshot-checked against `fixtures/all-six-gallery.tex`. It is not a second renderer. The original `all-six.tex` remains unchanged for D smoke. `tikz.node.mode` is an editor selector, **not** a TikZ key; math mode inserts trusted raw TeX inside math delimiters.
