# N3 · Общий каталог → офлайн-поиск и CLI, сквозной блок

Дата: 2026-11-01. Репозиторий: только i-shutov/tikzarium.
Базовый main: bef820ecc6565280d3381486239117092d16334d.
B32 PR #75 владеет исправлением Open/Reopen: этот блок не меняет GUI и
не копирует старые B/QA ветки.

## Исполняемая вертикаль
C-владелец: единый публичный read-only search API поверх существующего
Catalog::bundled() и 6 инструментов, всех параметров, четырёх библиотек.
A/CLI-проекция: help [--all|запрос|точный ID] с подробным русским ответом,
проверенным примером, исходной ссылкой и честной пометкой default.

## Проверки
- Поиск кириллицы/латиницы, точные ID, параметры и библиотеки.
- Неизвестные запросы — ошибка, нет выдуманной документации.
- Нет проверки наличия пакета, установки, компиляции или GUI-адаптера
  через один только поиск.
- CLI работает без настроенного XeLaTeX, файлов пользователя и сети.
- Cargo --locked fmt/test/clippy и smoke в настоящем Linux CI;
  hosted Windows Server/macOS ARM Rust тесты, без физического PASS.
- Прямые ссылки на руководство — атрибуты единого C-каталога,
  не новая независимая база.

## Границы
Это offline search/CLI для живой справки и повторного использования
в GUI. Встраивание поискового виджета в egui требует отдельного
B-owned интеграционного блока после B32, не через перезапись активной ветки.
Не добавляет PGF интерпретатор, CAS, solver или TeX-бандл.
