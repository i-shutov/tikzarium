## User-visible acceptance target

A line/arrow/rectangle/circle/node/Bézier pointer gesture is backed by the one C catalogue. A tool with a missing `tikz` package or `arrows.meta` library is not silently activated. The properties pane shows a reviewable **addition diff** against the preamble; the user accepts once and can Undo without losing comments, unicode text or unknown macros. A tool that encounters an opaque preamble is UNKNOWN and remains source-first. Accepted gestures immediately reveal/focus the generated line in the visible Split source editor (a redraw is required because the guide is after the source panel in egui's frame order).
