## D06.1 evidence-driven correction (same D PR, 2026-10-31)

The first actual hosted MiKTeX job [41187294741](https://github.com/i-shutov/tikzarium/actions/runs/41187294741) **FAILED**, not PENDING or PASS. Job 124496695332 installed a **real private MiKTeX 25.12** and successfully wrote `[MPM]AutoInstall=0`, but the strict whole-string comparison of `initexmf --show-config-value` failed because MiKTeX 25.12 emits advisory and INFO lines around the exact `0` numeric readback on the elevated hosted runner. The job therefore never reached explicit package installation, XeLaTeX build or PDF proof; artifact upload had no files to attach. This is a D QA parser defect, not proof of MiKTeX compilation failure.

Correction: a sourced PowerShell helper accepts precisely **one numeric line equal to 0** and requires successful process exit. It rejects 1, other numbers, extra numeric lines, empty output and nonzero exit. The original INFO/warning transcript is retained and only narrow numeric evidence is used; no global MiKTeX preference is changed. Host-only regression cases run *before* the slow installer. The setup creates an appendable failure-stage JSON before download so uploads after subsequent failures are useful. Do not infer any subsequent MiKTeX PASS before rechecking the new exact SHA and PDF/log artifacts. C07 #39 and B07 #37 remain independent draft PRs; handwritten D06 fixture is not a pointer-authoring acceptance test.
