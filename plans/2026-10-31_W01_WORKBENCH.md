# W01 — Native XeLaTeX workbench bootstrap
Date: 2026-10-31 · owner: integration · tracked: #2 #3 #4 #5

## Objective
Deliver source-open/edit/save → actual XeLaTeX → PDF preview/export across Windows 10 x64 and macOS ARM64, with a Rust-only application shell and modular package discovery. This is v0.1 **development work**, not a release claim.

## Vertical acceptance
- Cargo workspace containing independent core, CLI, app and extension registry.
- XeLaTeX path detection, explicit `-no-shell-escape`, `-recorder`, cancellation and 120-second timeout.
- Full-document XeLaTeX build in a temporary output directory, stable primary source.
- Source preservation on UTF-8 save; no format rewriting; errors and .fls information.
- First-page PDF raster preview via optional local `pdftoppm`; exact PDF bytes are exported.
- Desktop source editor, package panel (install ≠ compile ≠ visually edit) and build diagnostics.
- Quickstart and Cyrillic real fixtures; GitHub CI checks Windows-2022, macos-15 ARM and Ubuntu XeLaTeX.
- Plans/insights, status and remaining blockers recorded at same SHA.
