## Real user-facing vertical

- The B-owned interaction enum maps six pointer tools to C07 stable IDs; the C07 TOML catalogue (via `Catalog::bundled()`) supplies ALL six source templates, parameter metadata, requirements, Russian explanations, manual references, examples and documented editor-preset provenance. No separate B TikZ source generator or hard-coded table survives.
- B converts mouse coordinates/inspector values into explicit cm dimensions and calls `Catalog::generate()`; C validates literals, renders native TikZ and escapes plain node text. Arrow tips are chosen from C-defined allowed values. Node content has explicit literal-text or intentional raw mathematical TeX mode; no macro expansion or CAS in Rust.
- An owned source marker follows each generated command. Reopen only re-recognizes commands that round-trip *exactly* through C code generation. Modified/opaque code remains source-first and cannot be overwritten from the inspector.
- Split keeps source beside separate approximate guide and exact XeLaTeX PDF. The provisional guide is not a PDF coordinate inverse; no transformed/opaque scope alignment is claimed.
- Package `tikz` and, for arrow, `arrows.meta` are detected separately. Installed != project-loaded; an explicit visible `\\usepackage` or `\\usetikzlibrary` insertion is reversible. No package installation occurs. Source editor always remains available.
- B visual undo now records an exact post-edit source revision and byte span, rejecting intervening manual edits rather than replacing an unrelated matching substring. This is intentionally conservative, not an implementation of general editor undo.
