# AI88: исходные примеры AT4

В этот каталог 13.11.2026 приняты **17 неизменённых TeX-исходников AT4** из авторитетного набора AI88: ID 09, 34, 35 и 48–61. [Полный исходный catalogue.json](catalogue.original.json) содержит 88 записей; остальные 71 TeX-файл этим intake не добавлены. [Manifest](AT4_SOURCE_INTAKE.json) фиксирует ID, имя, размер, SHA256, исходный Drive URL, дату изменения, движок и предметный `check` каждого включённого примера.

Основание: [Scientific Studio 1.0 release scope](../../docs/RELEASE_SCOPE_SCIENTIFIC_STUDIO_1_0_RU.md), [рабочий план V2](../../plans/2026-11-11_SCI_1_0_EXECUTION.md), [полная 88-case таблица](../AI_TIKZ_SKILLS_2026-11-10_88_CASES.csv). Историческая отсрочка SC/AT после узкого Windows 1.0 отменена решением владельца 11.11; функциональные и научные критерии сохранены.

## Что подтверждено

Все 17 файлов получены как исходные байты и сверены по размеру и SHA256. Сохранены CRLF, комментарии, выражения, inline coordinates/tables, стили и неизвестные для Inspector конструкции. Их общий размер — **8 097 байт**. Исходный каталог: **50 287 байт**, SHA256 `4a94885064027806d4c9df7220216a160a923a4346671973365e59aa3cee94a5`.

В этих 17 оригиналах не обнаружены project-local `input/include` или внешние `.dat/.csv`; таблицы и координаты заданы внутри TeX. Отдельная синтетическая проверка внешних таблиц нужна для resource/provenance поведения и не заменяет эти ID.
