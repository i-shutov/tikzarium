## Finding
B01 previously decided freshness solely from PDF existence + input **text**. A user can build `drawing-a.tex`, Save As `drawing-b.tex` without changing text, then export the PDF under the new pathname. That incorrectly implies the preview was built from the new file; included relative images and TeX inputs could differ. B02 binds the last-success artifact to its compilation source **and pathname**; it marks the retained PDF stale and refuses export under the new filename. It does not delete last-good PDF.

A new compilation does not promote a prior PDF: while a worker runs, the retained PDF is conservatively stale and cannot be exported. This does not claim that unchanged external TeX dependencies are tracked; that requires a separate dependency freshness contract in the core.

B01 exposed menu buttons with no Command/Ctrl native shortcut equivalents. B02 adds keyboard dispatch with platform-neutral egui `Modifiers.command`; real OS acceptance remains outstanding. B02 also prevents active build worker identity changes by disabling Save As/Open/Save/TeX discovery, while still allowing source edits that correctly make the last-good preview stale.
