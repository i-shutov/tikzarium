## Contract and evidence
- `BuildError::TeXFailure` retains stable human `details` / `code` and now provides `diagnostics` with file and line, plus up to the in-memory log cap through `log_excerpt`.
- The accessor returns an empty slice / None for non-TeX errors; consumers cannot mistake a timeout for a TeX compiler error.
- The original `.log` can still be saved verbatim at `BuildOptions.log_path`; the excerpt is explicitly NOT guaranteed to contain the entire long TeX log.
- Failure integration fixture validates line 9, log excerpt, persisted full TeX log and byte-identical input.
- Rust compiler absent in current execution sandbox; tests at the new SHA must be judged only from fresh GitHub CI, not assumed from a clean parent branch.

## Known limitations
This is not a process-tree sandbox. `-no-shell-escape` does not prevent arbitrary file access by TeX. B GUI has not yet wired click-to-error from the new error API. macOS hosted build and Windows Server CI are NOT physical M1/M4 or Windows 10 GUI smoke tests. Keep the PR draft until all CI evidence is checked.
