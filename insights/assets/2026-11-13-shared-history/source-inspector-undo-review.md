## Source findings and bounded fix

At the starting head, production source Undo remained split between `SourceHistory` for typing and `Session::undo` for authored patches. `fence_source_editor_undo_on_revision_change` set the native reset flag after Inspector Apply; the subsequent `show_source_editor` called `source_history.reset`, dropping earlier typing. Conversely `Session::sync` clears its visual inverse stack after manual typing. Thus the existing isolated SV-001 Apply → Undo test did not prove the mixed production sequence manual typing → Apply → Undo → Undo, or its reverse.

The integrator expanded this reviewer task to a bounded fix. Production handlers now transfer their existing exact inverse SourcePatches from Session to the same bounded `SourceHistory` ledger as typing. Adjacent inverse revisions and total revision advance are checked before/while registering the chain; a mismatch resets unsafe history. Idle handlers return without cloning/diffing a document, and the standalone inverse stack is drained rather than duplicated. Native TextEdit snapshots are still revoked at source-patch/view boundaries, but that no longer resets the app ledger. Open explicitly resets the app ledger, Inspector state and deferred source input. A one-frame input fence also clears old events already delivered to egui before the loaded source renders; it expires at update end so a Canvas-only or late-frame Open cannot discard future fresh input. Shared Undo/Redo changes the authoritative `document.source`, invokes Session's existing source-change invalidation, and cancels any in-flight drawing capture. Standalone Session APIs and historical unit regressions remain intact. The production action bar and shortcut routing use the shared ledger; the production guide does not replay its separate Session-only shortcut fallback.

Four new focused production-shell regressions PASS (raw log `mixed-shell-tests.log`). They drive the actual scientific Inspector with raw egui pointer events (scan, command combo, literal field, Apply), and type through the actual source view/raw-input hook. They cover both manual/Inspector orderings, exact CRLF/Unicode/unknown definition/comment preservation, two-step Undo, Redo by Ctrl+Y/Shift+Z, branch after Undo, Save/Open identity/input fences, expected-byte mismatch and unregistered revision rejection.
