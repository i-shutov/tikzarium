# W01 — Research, evidence and limitations
Date: 2026-10-31

## Confirmed engineering decisions
- The actual rendering authority is **XeLaTeX** PDF. Rasterized PNG is a viewport surrogate only.
- TeX package lookup through kpsewhich is not evidence of successful compilation or visual editability.
- Rust semantic/editable model is optional and may only modify known source spans. All custom macros remain opaque.
- Package discovery should not execute a process on each egui animation frame; cache status and refresh explicitly.
- A build started on source revision R must not later be marked fresh if the editor has changed to revision R+1.
- Cancelled and timed-out compilation should not replace the last-good PDF.

## Verified in sandbox, outside Rust binaries
Host: Linux x86_64 with TeX Live 2025/dev/Debian XeTeX; NOT user Win10 or macOS ARM.
- `xelatex -interaction=nonstopmode -halt-on-error -file-line-error -recorder -no-shell-escape ... quickstart.tex` generated 1-page PDF (187.46 x 28.74 pt).
- Same for `cyrillic.tex`, 1-page PDF (612 x 792 pt).
- `pdftoppm` rasterized quickstart to PNG, 1200px target.
- PDF SHA-256 quickstart: `8d4dfdd5c816879cb7f6a1c7b7246222a28a63f88bcae5d3bc6e35313a1782b5`.
- PDF SHA-256 Cyrillic: `7f68c0ac243104d1863ec809e474629499d5e52701cb38cb256e9fb4e74874fb`.
- These results validate example TeX and external renderers only, **not** Rust BuildService behavior.

## Not verified at this checkpoint
- Cargo build/tests: rustc/cargo are unavailable in this sandbox. GitHub CI must independently compile the branch.
- Native GUI process, file dialog, PDF preview, cancellation and save flow: no Rust executable or desktop acceptance evidence yet.
- Actual Mac ARM64 and Windows 10 app: pending manual smoke.
- Feature-complete TikZ/PGF visual editing: not implemented.
- `xelatex -no-shell-escape` is safer but does not sandbox arbitrary TeX reads/writes.

## Context from user graphics R4
R4 references 135 successfully compiled active examples, 158 PDF pages, 18 semantic tests and 131 strict warning-gate passes. Four original warning anomalies O027/O028/O030/O047 remain unresolved. The R4 CI corpus has not yet been imported or rerun on either target OS.

## Lessons
Fastest reliable release path: runnable XeLaTeX workbench → verified native preview → minimal source-preserving visual editor → geometry DAG → extension adapters. Do not build a universal TeX interpreter in Rust. Keep all claims tied to reproducible environment and Git SHA.
