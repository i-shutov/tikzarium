Удалённая ветка `feat/studio-scientific-integration-20261112` оставалась на `eb9d415e796d9e84f14550f417c1ebfb272016b7`, tree `c4f8a38451dce105995d2bf9f0a92a7202448325`. CP03 помечен `RECOVERED_UNVERIFIED` и сам по себе не содержит финальной интеграции.

На странице 6 атласа найден точный app source tree `6c3208dc309a4c31ba36c4cf3ccda63b85083bd9`. GitHub сохранил это дерево и все его blobs, хотя ветка PR ещё не ссылалась на них. По этим объектам восстановлены **все 25 файлов `crates/tikzarium-app/src`**. Их Git hashes и дерево побайтно совпали с указанными в атласе. Реконструкция интерфейса по картинкам и ранние предложения работников не включены в код.

Основа восстановлена из архива CP01 и двух опубликованных commits после него. Все **1440 записей опубликованного дерева** сверены с GitHub; восстановлен также исторический SCI-BUILD evidence ZIP. Воспроизведены точный base tree и объект commit `eb9d415e…`. Таким образом, новый блок продолжает существующую ветку без потери её файлов.

Локальный кандидат прежнего процесса `fe85cc604b5c32ff8ac1c5e09efd694b59a4b4a7` указан в атласе, но его commit object не найден. Он не выдаётся за новый опубликованный commit. Соответствие исходников доказано именно через сохранённое app tree. Новый опубликованный SHA и контрольные суммы пакета фиксируются в delivery receipt и описании PR после завершения записи.

## Поведение восстановленного интерфейса

- Верхнее меню: **Файл, Правка, Вид, Сборка, Справка**. Частые команды находятся в отдельной компактной строке.
- Векторные иконки, штатные кнопки egui, подписи для accessibility, hover и disabled-состояния. Верхние targets 32 egui pt, инструменты 30 pt, полоса инструментов 46 pt; компактный базовый interaction size 26 pt, код по умолчанию 14 pt.
- Порядок рабочих областей: **исходник → инструменты → холст/PDF → Inspector**. Инструменты примитивов выбираются одним нажатием.
- Номера физических строк находятся в отдельном gutter. Перенос длинной строки не создаёт новый номер; горизонтальная прокрутка кода не уносит gutter.
- Преамбула показана отдельным сворачиваемым блоком над телом рисунка. Оба представления изменяют участки единственного авторитетного source buffer. Для неоднозначного/opaque TeX остаётся весь исходник с явным объяснением.
- Undo/Redo исходника используют ограниченную историю с проверкой revision и ожидаемых байтов; поиск, замена и переход к строке работают с глобальными смещениями. Переключение представления не является правкой файла.
- Сохранены четыре темы: Midnight, Light, Dark и Paper. Цвет оболочки не изменяет TeX или PDF.

Отдельный поздний архив оригинальных native журналов этого блока не восстановлен; встроенные кадры и подписи атласа не объявляются новой независимой приёмкой.

Эргономика в атласе — геометрическая оценка шести маршрутов между центрами целей: среднее расстояние 1321,8 → 560,9 screenshot px (−57,6%). Прямая активация каждого из шести инструментов остаётся одним click.

## CI и продолжение

До публикации точного восстановленного блока PR-triggered snapshot `eb9d415e…` содержал 12 workflows: 9 success, 3 failure. I61 и N5 остановились на прежних `APP_TREE` leases до своих GUI/packaging сценариев; у SCI142 Inspector macOS job был cancelled без steps, Linux/Windows jobs прошли. Это не общий CI PASS и не доказанная ошибка новой реализации.

После обновления ref проверять **новый SHA**. Старые leases не заменять механически: исходные сценарии и координаты требуют проверки на компактной раскладке. Приоритет следующего блока — native 1366×768 `PGFPlots → Inspector → SourcePatch → Undo → Save/Open → XeLaTeX → PDF` на одном exact source tree с оригинальными кадрами, `.tex`, PDF, logs и checksums; затем соответствующие hosted/native acceptance gates. Уже действующие требования scientific release scope сохраняются.

Из static review оставлены два небольших follow-up: доступное имя running-build кнопки отмены сейчас является символом квадрата; смешанные nonstandalone/standalone `begin{document}` относятся к неподдержанной структуре, где граница fold может быть неточной. Ни один пункт не изменяет байты через сворачивание; весь исходник всегда доступен. Эти правки не подмешивались в точное восстановление проверенного app tree.
