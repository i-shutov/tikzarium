## 2. Реальные GUI-свидетельства на 96 DPI

- Зафиксированы активная `WinSta0/Default`, WTS Active, PID и HWND своего приложения, клиент 1180×680 при 96 DPI. Это запись исходного локального рабочего процесса; удалённый независимый ревьюер **не присутствовал в живом RDP-сеансе**.
- **13 оригинальных PNG** декодированы независимо. Каждый размером **1180×680**, все **13 имеют различные декодированные пиксели**. Проверены полная клиентская область, F1/справка, исходник рядом с холстом, свойства, нижняя статусная строка, последовательные инструменты, состояние сохранения/повторного открытия, Undo и вкладка PDF. Признаков включения постороннего рабочего стола в эти клиентские кадры не обнаружено.
- Сверены **13 структурированных событий** `events.jsonl` c `w3-original.json`: порядок, PID/HWND, session ID и `Default` согласованы; временные метки возрастают. Это **локально записанная телеметрия**, она не является криптографическим доказательством реальных событий ОС.
- Последовательные `.tex` содержат **1→2→3→4→5→6** TikZ-owned команд в порядке `line`, `arrow`, `rectangle`, `circle`, `node`, `cubic`; исходные не принадлежащие редактору строки сохранены **побайтно**. Седьмая команда добавлена отдельно; `saved.tex = reopened.tex = undo.tex = cubic.tex` побайтно. Для Open/Save/Undo — убедительное независимое файловое подтверждение.
- В промежуточной первой попытке GUI был зафиксирован `LINE_MISSING`, когда непрозрачное объявление шрифта стояло до TikZ imports. **Не скрыто**: этот первый прогон остался в `candidate-run/` с исходным журналом, успешный повтор — в `candidate-retry/`, без приписывания первого отказа успешному сценарию.

## 3. XeLaTeX → PDF / Unicode

Независимо прочитаны оригинальный `figure.pdf`, `figure.tex` и GUI-log; выполнены системные `pdfinfo`, `pdffonts`, `pdftotext` на **скачанном PDF**, не на заявленном текстовом отчёте. Результат: **одна страница**, 338×489,03 pt, PDF-файл 19 128 байт; `pdffonts`: `ArialMT`, embedded=`yes`, sub=`yes`, ToUnicode=`yes`; `pdftotext`: строка **«Точка»** присутствует.

PDF дополнительно отрисован в независимом окружении и визуально просмотрен: русская надпись находится **отдельно от первоначальных узлов**; отображены шесть созданных фигур и исходная схема. В GUI-снимке PDF видно тот же файл. Зафиксирован действительный вывод `Output written on ...figure.pdf (1 page)` в XeLaTeX-журнале, предупреждений `Missing character` в успешном журнале **нет**. Есть **нефатальное** предупреждение MiKTeX о давно не выполнявшейся проверке обновлений; не следует выдавать его за ошибку GUI. Поле `xelatex_exit_code=0` в manifest базируется на **локальном сообщении GUI об успехе**, а не на самостоятельно наблюдаемом удалённым ревьюером коде процесса.

Отдельный архив предыдущего прогона содержит свидетельства ввода `тест` через русскую клавиатуру. Сохранённая `.tex` действительно содержит `тест`, но независимый ревьюер не наблюдал собственно ввод — поэтому это **PASS по документированному физическому локальному прогону**, а не удалённое доказательство IME composition.

## 5. Рекомендуемые следующие действия

Продолжить **именно 125% и 200% DPI** из настоящих интерактивных сессий — через параметры `.rdp` на клиенте с обязательной проверкой `GetDpiForWindow` 120/192, либо через консольный/VNC/KVM доступ провайдера. Не менять системную безопасность, не выдавать RDP bitmap scaling за physical DPI. Затем выполнить W2b и W4; `main` и релизный кандидат при каждом новом SHA перепроверять на отсутствие регрессии. Оригинальные ZIP/PNG/PDF остаются в закрытом Drive и не должны попадать в публичный репозиторий.
