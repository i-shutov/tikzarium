# TikZarium Windows 1.0 — известные ограничения и непроверенные режимы

> Релизный комплект ещё находится на стадии подготовки. Это **не** утверждение наличия дефекта там, где испытание не выполнялось. Версия scope: Windows10 x64, физически проверено **100% / 96 DPI**.

## Дисплей и RDP

- **125% / 120 DPI** и **200% / 192 DPI**: не квалифицированы для 1.0 по решению владельца от 10.11.2026. Планы испытаний перенесены в [#161](https://github.com/i-shutov/tikzarium/issues/161); не выставлять PASS/FAIL до реального теста.
- GUI использует OpenGL2+; некоторые Windows RDP-сеансы не предоставляют подходящий OpenGL. Применявшаяся в лабораторных тестах Mesa llvmpipe работала с DLL только в каталоге QA и **не входит в пользовательский portable-дистрибутив**. Нативный запуск на совместимом GPU требуется проверить в W4 clean-machine.

## Шрифты / ввод

- XeLaTeX не гарантирует кириллицу в шрифте Latin Modern Sans, который может выбираться через `\sffamily` стартового примера. При вставке `Точка` получено `Missing character`; успешная физическая проверка PDF выполнялась с явно установленным Arial, embedded+ToUnicode. Пользователь должен выбрать реально установленный кириллический fontspec-шрифт; приложения не должны автоматически менять произвольные `.tex` и не распространяют Arial. См. [#159](https://github.com/i-shutov/tikzarium/issues/159).
- Русская клавиатурная раскладка проверена через физические события; сложный IME composition/preedit (например, для японского/китайского) не проверен. Не записывать IME composition как PASS на основании вставки из clipboard или русской раскладки.

## Дистрибутив / зависимости

- Подтверждённый CI-кандидат — **переносимый ZIP**, не полноценный MSI/EXE-инсталлятор; для stable требуется отдельно принять W4 на чистом Windows10 (развёртывание, запуск, удаление и откат).
- Внешние MiKTeX/XeLaTeX и необходимые пакеты пользователь устанавливает отдельно; программа не включает TeX и шрифты, shell escape по умолчанию отключён.
- Подпись исполняемого файла/инсталлятора пока не подтверждена. До реальной проверки сертификата не сообщать «подписано»; об отсутствии подписи предупреждать открыто.
- Физический Windows Server W2b full UI acceptance, а также clean-machine W4 — отдельные release gates и пока не подтверждены. Дополнительные 120/192 DPI-прогоны **не являются** частью W2b/W3 gate для 1.0.
