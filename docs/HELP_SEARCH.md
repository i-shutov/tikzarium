# N3 · Офлайн-поиск в общем русском каталоге TikZarium

Это функциональная CLI-проекция **того же** C-каталога, который использует egui.
Отдельная база справки или новая модель TikZ не создаются.

Команды:

    tikzarium-cli help
    tikzarium-cli help --all
    tikzarium-cli help окружность
    tikzarium-cli help tikz.arrow:tip
    tikzarium-cli help tikz.library.positioning

Полный ответ содержит оригинальный ID и синтаксис, русское пояснение, пример,
требования пакета/библиотеки/движка, версию PGF/TikZ, на которую опирается
запись, ссылку и раздел руководства. Для параметров дополнительно выводятся
тип, единицы, допустимые значения, сведения о default/provenance,
предупреждения и взаимодействия. Редакторская предустановка **никогда**
не выдаётся за документированный default TikZ. Неподтверждённое значение —
UNKNOWN.

Режим help не ищет установленный XeLaTeX, не запускает TeX, не меняет проект,
не устанавливает пакеты и не переписывает CRLF, макросы или исходные файлы.
Установка и подключение пакетов не проверяются: NOT_CHECKED. Отдельный
tikzarium-cli doctor выполняет read-only runtime-проверки.

Текущее покрытие общего каталога: шесть встроенных инструментов,
их параметры и четыре документированных записи библиотек
arrows.meta, positioning, calc, fit. Эти библиотечные записи описывают
возможности и требования, но не обещают наличие графического адаптера.
Lua-only графические расширения не объявляются совместимыми с XeLaTeX.

**Приёмка:** cargo fmt/test/clippy на точном HEAD; один CLI smoke с
отсутствующим путём TIKZARIUM_XELATEX; реальный вывод кириллицы и
происхождения preset; отдельные hosted OS проверки. Это не physical
Win10/M1/M4 acceptance и не завершённая GUI-поисковая строка.
