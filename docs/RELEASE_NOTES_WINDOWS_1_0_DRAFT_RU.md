# TikZarium 1.0 — Windows x64 (черновик релизных заметок)

> **DRAFT — НЕ ПУБЛИКОВАТЬ как stable до W2b/W3/W4.** Версия целевого выпуска: `v1.0.0`. Черновик зафиксирован по коду `main` `488a9687c404f9714eecbcb8ccb4edbf97a54d89` и может потребовать обновления после ревью PR #155–#157.

## Что делает TikZarium

TikZarium — локальный редактор TikZ/PGF на Rust/egui. Исходный `.tex` остаётся редактируемым и авторитетным: визуальные инструменты помогают создавать TikZ-команды, но не заменяют TeX и не навязывают проприетарный формат документа.

В текущем исходном коде есть визуальный холст и редактирование рядом с исходником; инструменты линии, стрелки, прямоугольника, окружности, текстового/математического узла и Bézier; справка F1/Inspector с описаниями синтаксиса; операции Undo, Save/Open; генерация PDF через **внешний XeLaTeX**. Для нового несохранённого документа Build ▶ открывает встроенный диалог «Сохранение перед сборкой» с отменой.

## Комплект для Windows

- Переносимый пакет x64 (архив ZIP), приложение `tikzarium-app.exe` и `tikzarium-cli.exe`, `README_RU.md`, `PROVENANCE.json`, `MANIFEST.sha256`, тестовый `.tex`.
- **Не установщик**: MSI/Setup.exe не входит в представленный QA-кандидат.
- **MiKTeX/XeLaTeX устанавливается отдельно** и обнаруживается приложением; автоматическая инсталляция пакетов и shell escape не должны включаться скрытно. Поддерживаемость каждого PGF/TikZ пакета зависит от установленной среды и входного документа.
- При запуске необходим совместимый OpenGL-контекст (для GUI текущая `egui_glow` требует OpenGL 2.0+). Для тестирования под некоторыми RDP-сессиями применялся **изолированный Mesa llvmpipe как QA workaround**; он **не входит в релиз**.

## Важное ограничение кириллических глифов

Стартовый рисунок использует `\sffamily`, при этом может выбираться Latin Modern Sans **без кириллических глифов**. Сам по себе успешный exit 0 XeLaTeX не гарантирует наличие русских букв: проверяйте предупреждения `Missing character`, `pdftotext` и `pdffonts`. На Windows 10 в физической GUI-проверке после явного `\setsansfont{Arial}` PDF с «Точка» собрался, шрифт был встроен с ToUnicode. Шрифт **не поставляется** с TikZarium. Не применять автоматическую подмену шрифтов к произвольному `.tex`. Подробности — [#159](https://github.com/i-shutov/tikzarium/issues/159).

Кириллица в физическом тесте вводилась через буфер обмена; настоящий Windows IME и DPI 125%/200% пока не испытаны.

## Что нужно знать до установки

- Основная целевая платформа: Windows 10 Pro x64 22H2, build 19045+, отдельные проверки на Windows 11 являются дополнительной совместимостью. Поддержка macOS ARM64 и Linux проверяется отдельными сценариями и не выдается за физическую Win10 приёмку.
- Нужны установленные шрифты для выбранных `fontspec` семейств. Продукт не распространяет пользовательские или проприетарные шрифты.
- Подпись Windows исполняемых файлов/установщика **ещё не подтверждена**; не указывать «подписано» до фактической проверки сертификата и подписи.
- Известные предметные ограничения: неизвестные пользовательские макросы сохраняются как исходный TeX; визуальное редактирование поддерживает только выражаемые в текущем TikZ-каталоге конструкции. Холст — предварительный; точное PDF-изображение выдаёт XeLaTeX.
- Критический релизный аудит: полнота GUI→PDF, native dialogs, Unicode, IME, DPI и активная интерактивная сессия Windows. Пока эти испытания не подтверждены оригинальными evidence по финальному релизному SHA, выпуск **QA candidate**, не stable.

## Целевой набор проверок перед объявлением stable

1. Подлинный SHA источников и ZIP manifest, CRC, PE GUI/CLI subsystem и импортов; локальный запуск без системных изменений.
2. Шесть реальных графических действий, source-integrity и Undo/Save/Open в Windows 10.
3. GUI→XeLaTeX→PDF с кириллицей, математикой, Arial/ToUnicode и проверкой лога/байтов PDF.
4. Чистая установка/удаление, предупреждения о неподписанном коде, документация требований и Known Issues.
5. Физическая независимая приёмка W2b/W3, CI Windows/macOS/Linux, затем явный GO на `v1.0.0`.
